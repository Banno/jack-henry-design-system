# Row

[Guidelines](https://jackhenry.design/pages/components/row/)

<hr />

Row is a layout primitive that arranges elements slotted into it in a single horizontal row.
It uses Flexbox under the hood, stacking slotted elements from left to right.

## Usage

Import the `<forge-row>` component:

```javascript
import '@jack-henry/jh-elements/components/row/row.js';
```

Place elements in the default slot. Each slotted element becomes a flex item stacked horizontally:

```html
<forge-row gap="100" align="center">
  <jh-button label="Save"></jh-button>
  <jh-button label="Cancel"></jh-button>
</forge-row>
```

## Spacing

`gap` and `padding` both map to the `--jh-dimension-*` token scale, so spacing stays consistent with the rest of the design system.

- `gap` sets the space between slotted elements.
- `padding` sets the inner padding between the container edges and its slotted elements.

Both accept the same values: `0`, `25`, `50`, `100`, `200`, `300`, `400`, `500`, `600`, `700`, `800`, `900`, and `1000`.

```html
<forge-row gap="200" padding="100">
  <!-- slotted elements -->
</forge-row>
```

## Alignment

`align` and `justify` control how slotted elements are positioned:

- `align` sets the cross-axis (vertical) alignment via `align-items`: `start`, `end`, `center`, `stretch`, or `baseline`.
- `justify` sets the main-axis (horizontal) distribution via `justify-content`: `start`, `end`, `center`, `between`, `around`, or `evenly`.

```html
<forge-row align="center" justify="between">
  <!-- slotted elements -->
</forge-row>
```

## Wrapping

By default slotted elements stay on a single line and may overflow the container. Add the boolean `wrap` attribute to let slotted elements reflow onto new lines when they run out of space along the main axis.

```html
<forge-row wrap gap="100">
  <!-- slotted elements -->
</forge-row>
```

## Composition

Layout primitives are designed to compose. Because `<forge-row>` is itself a valid flex child, it nests freely inside `<forge-column>` and other `<forge-row>` containers. See [Layout Composition](?path=/docs/primitives-layout-composition--docs) for common patterns such as toolbars, card layouts, and form rows.

## Component API

For boolean attributes, true indicates that the attribute has been set without a value: `<forge-row wrap></forge-row>`. While false indicates the attribute does not exist in the DOM: `<forge-row></forge-row>`.
