# Paragraph

<hr />

`<forge-paragraph>` is a text component for regular reading text and descriptions. Can be used anywhere you would normally use a standard `<p>` tag.

## Usage

Import the component:

```javascript
import '@jack-henry/jh-elements/components/paragraph/paragraph.js';
```

To use `forge-paragraph>`:

```html
<forge-paragraph>
  Your statement is ready. You can download a PDF copy or view it online.
</forge-paragraph>
```

## Accessibility

This component satisfies [WCAG 2.2](https://www.w3.org/TR/WCAG22/) AA success criteria.
The following success criteria are of concern:

- [WCAG 1.3.1 Info and Relationships](https://www.w3.org/WAI/WCAG22/Understanding/info-and-relationships.html): Information, structure, and relationships conveyed through presentation can be programmatically determined or are available in text.

- [WCAG 1.4.3 Contrast (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html): The visual presentation of text and images of text has a contrast ratio of at least 4.5:1.

- [WCAG 1.4.4 Resize Text](https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html): Except for captions and images of text, text can be resized without assistive technology up to 200 percent without loss of content or functionality.

### What we provide

- To satisfy [WCAG 1.3.1 Info and Relationships](https://www.w3.org/WAI/WCAG22/Understanding/info-and-relationships.html), `<forge-paragraph>` renders its content inside a native `<p>` element, so assistive technology can programmatically determine it as paragraph text.

- To satisfy [WCAG 1.4.4 Resize Text](https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html), `<forge-paragraph>` can be resized without assistive technology up to 200 percent without loss of content or functionality.

### Author Guidance

- To satisfy [WCAG 1.4.3 Contrast (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) when `<forge-paragraph>` is placed on a non-default background (for example, inside a colored container), set the `--forge-paragraph-color-text-enabled` styling hook to a value that maintains sufficient contrast.
