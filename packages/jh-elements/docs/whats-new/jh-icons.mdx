# jh-icons 

### New Icons:

Icons 2.0 introduces 149 new icons to the icons library. See the [icon gallery](https://release-v2--68f8e6a25b256d0ef89b13e6.chromatic.com/?path=/docs/iconography-gallery--gallery) to explore the full, updated collection.

### New Sizing 
Icons now support a new `xx-large` sizing option, along with a corresponding styling hook (`--jh-icon-size-extra-extra-large`) for easy overrides.

### Deprecated Icon:

- The `jh-icon-shield-check` icon has been replaced by the `jh-icon-shield-checkmark` icon.
