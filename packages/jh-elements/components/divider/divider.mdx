# Divider

[Guidelines](https://jackhenry.design/v2/components/divider/)

<hr />

Dividers are used to group content vertically or horizontally at the page or component level and should be used when whitespace does not provide a clear enough separation. 

## Usage

Import the `<jh-divider>` component.

```javascript
import '@jack-henry/jh-elements/components/divider/divider.js';
```

Declaring a `jh-divider`:

```html
<jh-divider inset="8"></jh-divider>
```

## Inset Override for Horizontal Dividers

There are thirteen inset options available to help align the horizontal divider with its associated content. If an inset outside of the thirteen provided options is desired, use the `--jh-divider-space-inset` component token. Note that if both the `inset` property and `--jh-divider-space-inset` component token are present, the `inset` property will take priority for that instance of the component. 

## Right-to-Left Support

Dividers support right-to-left (RTL) layouts. Set `dir="rtl"` on the divider or on any parent element, and the divider will flip to match.

The inset starts at the inline-start edge (the left edge in left-to-right layouts and the right edge in right-to-left layouts). This applies to both the `inset` property and the `--jh-divider-space-inset` component token.

```html
<div dir="rtl">
  <jh-divider inset="16"></jh-divider>
</div>
```

This is documented here for now and will move to a general RTL page once broader right-to-left support lands.

## Accessibility

This component satisfies [WCAG 2.2](https://www.w3.org/TR/WCAG22/) AA success criteria. The following success criteria are of concern:

- [WCAG 1.3.1 Info and Relationships](https://www.w3.org/WAI/WCAG22/Understanding/info-and-relationships.html): Information, structure, and relationships conveyed through presentation can be programmatically determined or are available in text.

### What we provide

- To satisfy [WCAG 1.3.1 Info and Relationships](https://www.w3.org/WAI/WCAG22/Understanding/info-and-relationships.html), the divider has a role of `separator` and an `aria-orientation` that reflects the `orientation` property, enabling assistive technologies to programmatically determine the divider's purpose and direction.
