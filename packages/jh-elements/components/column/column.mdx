# Column

[Guidelines](https://jackhenry.design/pages/components/column/)

<hr />

Column is a layout primitive that arranges elements slotted into it in a single vertical column.
It uses Flexbox under the hood, stacking slotted elements from top to bottom.

## Usage

Import the `<forge-column>` component:

```javascript
import '@jack-henry/jh-elements/components/column/column.js';
```

Place elements in the default slot. Each slotted element becomes a flex item stacked vertically:

```html
<forge-column gap="100">
  <jh-button label="Save"></jh-button>
  <jh-button label="Cancel"></jh-button>
</forge-column>
```

## Spacing

`gap` and `padding` both map to the `--jh-dimension-*` token scale, so spacing stays consistent with the rest of the design system.

- `gap` sets the space between slotted elements.
- `padding` sets the inner padding between the container edges and its slotted elements.

Both accept the same values: `0`, `25`, `50`, `100`, `200`, `300`, `400`, `500`, `600`, `700`, `800`, `900`, and `1000`.

```html
<forge-column gap="200" padding="100">
  <!-- slotted elements -->
</forge-column>
```

## Alignment

`align-x` and `align-y` control how slotted elements are positioned:

- `align-x` sets the horizontal alignment via `align-items`: `start`, `end`, `center`, `stretch`, or `baseline`.
- `align-y` sets the vertical distribution via `justify-content`: `start`, `end`, `center`, `between`, `around`, or `evenly`.

```html
<forge-column align-x="center" align-y="between">
  <!-- slotted elements -->
</forge-column>
```

## Wrapping

By default slotted elements stay in a single column and may overflow the container. Add the boolean `wrap` attribute to let slotted elements reflow onto new columns when they run out of space along the main axis.

```html
<forge-column wrap gap="100">
  <!-- slotted elements -->
</forge-column>
```

## Composition

Layout primitives are designed to compose. Because `<forge-column>` is itself a valid flex child, it nests freely inside `<forge-row>` and other `<forge-column>` containers. See [Layout Composition](?path=/docs/primitives-layout-composition--docs) for common patterns such as toolbars, card layouts, and form rows.

## Component API

For boolean attributes, true indicates that the attribute has been set without a value: `<forge-column wrap></forge-column>`. While false indicates the attribute does not exist in the DOM: `<forge-column></forge-column>`.
