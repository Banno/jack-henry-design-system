# Primitives

Primitives are helpful building blocks to ensure consistency across your UI.

## Layout primitives

Use layout primitives to arrange other components. 

- **[Layout V Stack](?path=/docs/primitives-layout-v-stack--docs)** — arranges
  its children in a vertical column (`display: flex; flex-direction: column`).
- **[Layout H Stack](?path=/docs/primitives-layout-h-stack--docs)** — arranges
  its children in a horizontal row (`display: flex; flex-direction: row`).

Both stacks expose `gap` and `padding` (mapped to dimension tokens) and
`align`, `justify`, and `wrap` (mapped to flexbox).

### Seeing them in action

Individually these primitives don't mean much — they're designed to compose,
and a stack is itself a valid flex child, so they nest freely. See
**[Layout Composition](?path=/docs/primitives-layout-composition--docs)** for
real-world patterns: toolbars, nested-stack cards, form rows, and wrapping.

## Text primitives

Use text primitives to enforce consistent typography, semantic HTML hierarchy, and accessibility across your application.
