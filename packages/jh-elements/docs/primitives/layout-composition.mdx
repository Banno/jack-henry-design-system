# Layout Composition

The real power of the layout primitives shows when you combine them.
`<forge-row>` arranges its children in a row, `<forge-column>` arranges them in a
column, and because a stack is itself a valid flex child, they nest freely, so
you can compose them to build toolbars, cards, forms, and much more.

The examples below are named after the UI pattern they produce rather than the
components they use.

## Toolbar / split header

A title on the left with actions grouped on the right. `align-x="between"` pushes
the two groups to opposite ends of a `<forge-row>`.

<Canvas of={stories.Toolbar} />

## Split groups

Two groups pushed to opposite ends of the row with `align-x="between"`, while each
nested `<forge-row>` keeps its own `gap`. Use it to separate, say, a set
of navigation buttons from a set of actions.

<Canvas of={stories.SplitGroups} />

## Card layout (nested stacks)

A `<forge-column>` whose rows are `<forge-row>`s. Each header/footer
row can use its own `align-x` and `align-y` — nesting works because a stack is just
another flex child.

<Canvas of={stories.CardLayout} />

## Form row

A `<forge-column>` of labeled `<forge-row>`s. `align-y="baseline"`
keeps labels and values sitting on a shared text baseline, and `align-x="between"`
pushes each value to the opposite end of its label.

<Canvas of={stories.FormRow} />

## Wrapping

A `<forge-row>` with `wrap` so its children reflow onto new lines when the
container runs out of room. Resize the canvas to see the reflow.

<Canvas of={stories.Wrapping} />

## Larger form

A `<forge-column>` of stacked `<jh-input>`s, followed by a
`<forge-row>` placing two distinct `<jh-checkbox-group>`s side by side,
and an action row aligned to the end. Shows the primitives scaling up to a full
form.

<Canvas of={stories.Form} />
